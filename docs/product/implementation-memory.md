# Implementation record: persistent engineering memory (Prompt 4)

Implemented on 2026-10-01, building on lifecycle, external-agent and simulation-adapter phases.

- Added `ExperienceMemory` beneath the existing Engine/lifecycle. Managed history, lifecycle reasoning and external CLI/API share indexed cross-object experience retrieval. No parallel product engine, distributed scheduler or model calls were added.
- Kept exact evidence separate. Every declared reproducibility input must match and artifacts must verify; result caching stays disabled because arbitrary evaluator/environmental equivalence is not established. Imported claims cannot supply exact local evidence or acceptance.
- Added typed source references, request/requirements, quantitative applicability, material/load/process assumptions, outcomes, failure modes, claims, confidence basis, provenance, artifacts, supersession and scope. Harness observations may be simulation-supported; authored lessons remain hypotheses. There is no local hardware-measurement ingestion route.
- Added public `memory` commands and `/api/v2/memory` operations for search/browse/inspection, notes, supersession, exact lookup, portable export/import, projection repair and vector rebuild. Notes/imports are idempotent; supersession uses revision checks. Source references are scope checked.
- Indexed new SQLite documents with metadata/exact expression indexes and a transactional FTS5 projection. Atlas uses scoped metadata/text indexes and optional vector lookup. Bounded candidate search exposes lexical/vector/evidence ranking components; browse/reindex use keyset pages. Existing `Store.list` semantics and archived collections remain unchanged.
- Persisted memory workspace identity in `.davinci/memory-workspace-id`; moving a workspace preserves its namespace. Every memory operation also filters the active `project_id`. Explicit import is the cross-project sharing route. Unscoped historical rows are not silently adopted or upgraded.
- Decoupled embeddings from generation. Disabled by default; explicit `local-hash` has its own model/version/dimensions, zero API cost, no credentials/downloads and bounded lexical feature generation. Legacy `embeddings: true` cannot trigger paid calls. Vectors are rebuildable; lexical fallback is explicit. No learned or paid embedding adapter is shipped.
- Portable imports preserve source claim support, origin and history but always become `imported_unverified`. Payload hashes/size/path boundaries are checked, missing references are reported, and corrupted supplied bytes reject import. Metadata assertions from a portable file are not authenticated scientific evidence.

Public contracts, compatibility behavior and command examples are in [memory.md](memory.md). Atlas product setup is in [atlas.md](atlas.md); historical `scripts/atlas_setup.py` and study archives are unchanged.
